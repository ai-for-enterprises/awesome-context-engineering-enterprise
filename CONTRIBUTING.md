# Contributing

Thanks for your interest in contributing to **Awesome Context Engineering for Enterprise**! This list curates AI-powered tools evaluated through an enterprise lens -- security, compliance, scalability, and deployment flexibility.

## What to add

- **AI-powered or AI-enhanced** tools relevant to enterprise software engineering
- **Publicly accessible** with clear documentation
- **Enterprise-relevant** -- addresses needs like security, compliance, scalability, self-hosting, or audit controls
- **Factual descriptions** -- no marketing language

## How to contribute

1. Fork the repository and create a new branch
2. Add your tool to the **end** of the relevant section
3. Follow this format:

```markdown
- **[Tool Name](https://example.com)**: One-line description of what it does. `#pricing-tag`
```

**Pricing tags**: `#free` `#freemium` `#paid` `#enterprise` `#open-source` `#self-hosted`

4. Submit a pull request

## Rules

- One tool per line
- No duplicates (a tool may appear in multiple categories if relevant)
- Keep descriptions concise and factual
- Include accurate pricing information
- Do not add tools that are defunct or in private beta without public access
